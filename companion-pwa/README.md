# 公司数字员工工作台 · 手机伴侣端（PWA）

手机端伴侣应用，面向审批与提醒：审批人在手机上登录后查看待办（任务审批、计划提案、账号注册），
并直接执行「通过 / 驳回」。所有请求都走版本化服务端 API，不直连数据库。

## 功能范围

- 手机号 + 密码（+ 可选动态验证码）登录，获取短期 Bearer 会话令牌。
- 待办列表轮询（默认 30 秒），页面不可见时暂停轮询省电，回到前台立即刷新。
- 按类型执行审批：任务仅「通过」；计划提案、账号注册支持「通过 / 驳回（需填原因）」。
- 账号注册审批通过时**由审批人指定被分配的角色**（普通员工 / 部门负责人 / CEO / 超级管理员 / 客户管理员，与服务端 `_SUPPORTED_ROLES` 一致）。
- 会话过期（接口返回 401）时自动清理本地会话并要求重新登录。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `http://localhost:8000/api/v1` | 后端 API 基地址 |
| `VITE_APPROVAL_POLL_SECONDS` | `30` | 待办轮询间隔（秒）；非法或 ≤0 时回退 30 秒 |

## 本地命令

```powershell
npm install
npm run dev      # 本地开发（Vite）
npm run build    # tsc -b && vite build 产出 dist/
npm run preview  # 预览构建产物
npx vitest run   # 运行测试（必须加 run，否则进入 watch 模式）
```

## PWA 安装

构建后在移动浏览器打开站点，通过浏览器「添加到主屏幕」安装。`public/sw.js` 手写实现离线应用外壳缓存。

## 已知限制（未验收项，务必知悉）

- **令牌存储**：会话令牌保存在 `localStorage`，存在被 XSS 读取的风险。更安全的 httpOnly Cookie 方案需要后端改造，本轮未做。
- **提醒方式**：目前是**轮询式**（默认 30 秒），并非 Web Push。真实推送需要 HTTPS 与 VAPID 密钥，属未验收项。
- **图标格式**：manifest 使用位图 PNG（`192`/`512` 与 `512` maskable），并另提供 `apple-touch-icon.png`（180）；SVG 仅作浏览器 favicon。**真机安装性仍属未验收项**。
- **跨源部署**：前后端跨源时后端需显式配置 `WORKBENCH_CORS_ALLOWED_ORIGINS`（允许头已含 `Authorization`；留空即不放行任何跨源），**真实跨源部署属未验收项**。

## 安全约定

- 所有校验与权限判定在后端完成，前端仅作展示与交互。
- Service Worker **绝不缓存** `/api/` 前缀与跨源请求（认证接口响应含个人待办数据）。
- 不保存密码、验证码或原始密钥；会话令牌仅存于本地存储并随请求以 `Authorization: Bearer` 发送。
