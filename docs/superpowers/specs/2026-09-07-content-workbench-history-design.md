# 内容工作台历史草稿设计

## 目标

为公众号内容工作台增加独立的“历史草稿”视图，让用户能够找回、筛选并继续处理已有内容任务；管理员可以查看同一租户内所有任务，普通员工只能查看自己创建的任务。本阶段继续使用现有 Mock/适配器，不配置真实模型 API Key。

## 已确认范围

- 独立历史页面，不把历史列表挤进现有编辑页面。
- 列表默认按最近更新时间倒序。
- 每页 20 条，支持分页。
- 状态筛选：全部、待自检、失败、已确认。
- 列表展示主题、状态、创建者、更新时间。
- 普通员工只查询自己的任务；`super_admin` 与 `ceo` 查询同租户全部任务。
- 点击“继续处理”进入现有内容工作台并加载完整任务详情。
- 失败任务显示“重新生成”，沿用现有重新生成幂等键。
- 首次实现不加入关键词搜索、批量操作、导出或复杂审计时间线。

## 后端设计

### 查询接口

新增 `GET /api/v1/content-tasks`。

查询参数：

- `status`：可选，取 `reviewing`、`failed`、`confirmed`；缺省表示全部。
- `page`：可选，正整数，默认 `1`。
- `page_size`：可选，正整数，默认 `20`，限制在 `1..100`。

响应返回列表摘要和分页信息，不返回正文：

```json
{
  "items": [
    {
      "task_id": "task-123",
      "topic": "企业为什么要建立 AI 知识库",
      "status": "reviewing",
      "created_by": "employee-1",
      "created_at": "2026-09-07T12:00:00+00:00",
      "updated_at": "2026-09-07T12:04:00+00:00",
      "run_id": "run-123"
    }
  ],
  "page": 1,
  "page_size": 20,
  "total": 1,
  "has_next": false
}
```

服务层负责权限范围、状态校验、排序和分页。存储层提供按租户/创建者筛选任务摘要的能力；内存存储和 SQLite 存储保持相同语义。查询结果按任务的 `updated_at` 降序，必要时以 `task_id` 作为稳定的第二排序键。

非法状态、非正页码、超出页大小上限返回 `400`，不返回正文内容。越权请求必须表现为过滤后的空结果或无权范围内结果，不能泄露其他租户任务。

### 现有详情复用

历史列表项点击后调用现有 `GET /api/v1/content-tasks/{task_id}`，再将完整响应交给内容工作台。不会在列表接口复制 draft、sources 或审计详情。

## 前端设计

### 页面入口

在管理台导航中增加独立“历史草稿”入口，使用当前应用的 `AppShell` 与视觉规范。页面不复制编辑器逻辑，任务详情继续由 `ContentWorkbenchPage` 负责。

### 页面状态

页面包含：

- 顶部标题和任务总数。
- 状态筛选控件：全部、待自检、失败、已确认。
- 历史任务列表。
- 每行显示主题、状态、创建者、更新时间和“继续处理”。
- 失败行额外显示“重新生成”，点击后先加载任务，再复用工作台的失败恢复流程。
- 分页控件，上一页/下一页根据 `has_next` 和当前页禁用。
- 加载中、空列表、接口失败状态。

普通员工不在列表中看到其他人的创建者信息，因为服务端不会返回其他用户的任务；管理员可看到创建者字段用于区分任务归属。

### 恢复流程

点击“继续处理”时：

1. 请求详情接口。
2. 将任务 ID 写入路由或会话状态。
3. 打开内容工作台并加载详情。
4. 对 `reviewing` 进入可编辑状态，对 `failed` 显示失败原因和“重新生成”，对 `confirmed` 保持只读。

详情请求失败时，历史页显示错误提示并保留当前列表，不改变当前筛选和分页。

## 测试设计

### 后端

- 普通员工只能看到自己创建的任务。
- `super_admin` 与 `ceo` 能看到同租户全部任务，但看不到其他租户任务。
- 默认按更新时间倒序。
- 状态筛选只返回指定状态。
- 分页返回正确的 `total`、`page`、`page_size` 和 `has_next`。
- 非法状态、页码和页大小返回 `400`。
- 列表响应不包含正文或完整 draft 字段。
- 内存存储和 SQLite 存储覆盖相同查询行为。

### 前端

- 列表正确渲染状态、主题和分页信息。
- 切换状态筛选重新请求并刷新列表。
- 上一页/下一页按边界启用或禁用。
- 点击“继续处理”加载详情并进入现有工作台。
- 失败任务显示重新生成入口。
- 加载、空列表和错误状态可见且不破坏当前页面。

## 非目标

- 不接入真实模型 API Key。
- 不实现关键词搜索、批量删除、批量确认、批量重试。
- 不自动发布到微信公众号。
- 不改变现有内容任务状态机和重新生成幂等规则。
