| 项 | 内容 |

| **问题** | 两个前端技术底座完全不同——合并后留哪套？ |
| **现状实测** | `workbench-web`（**19,068 行**）= **AntD + Pro Components + zustand + react-query**<br>`admin-web`（**19,621 行**）= **零 UI 框架**（依赖只有 react/react-dom/eventsource-parser）+ **手写 CSS**（6 个文件含 `tokens.css`） |
