### ⚠️ 规格没写全的（空洞）—— 14 条

1. **【无权限验收】** §12 A1-A9 **无一条**覆盖 401/403/越权/跨租户：右栏对象（`?object=`）与深链 URL 的归属校验、设置弹窗条目对角色不可见时手改 URL 的行为，均无验收项。R4 L280 只提「无权时静默降级不注入」，但 §12 没有对应验收。
2. **【A6 的接口字段无契约落点】** A6 L254 要求「请求体含 `current_*_id`」，但规格全篇**未出现 `api-contract.md` / `permission-matrix.md`（grep 0 命中）**，也没有契约变更步骤；实测合约对 `current_account_id` / `contextFields` / 上下文注入 **0 命中** ⇒「带上下文唤起」落在哪个端点、字段名与可空性、未知字段是否 422 **一律未定**。实现侧 `RightPanel.tsx:16-18` 自述「本组件只显示要注入的字段名；真正的注入与权限判定要等数字员工面板（B2）合并进来」= 该验收项**目前不可独立验证**。
3. **【深链安全未写】** §8 只问「引不引 react-router」（L187-194），未定 URL 形态，也未写「地址栏是用户可编辑的输入、须当**不可信输入**处理」+ 对象归属校验；A5 L253 只要求「可直达/可刷新/可分享」，**缺「直达到他人对象必须拒绝或回落」的负例**。
4. **【「最近会话列表」缺数据与验收】** §2 L72 与 §4 L130 都要求侧栏常驻最近会话列表且与对话同一状态树，但 §12 **无一条验收它**，也未定取数端点/分页（既有 `GET /api/v1/conversations` 明确「必须分页」，`api-contract.md:761`）；既有资产 `admin-web/src/app/SidebarConversations.tsx`（+ 测试）**未被规格点名复用**。
