## 1. 接口清单与角色门禁

| 方法 | 路径 | 用途 | 角色门禁（**2026-09-20 实测**） | **矩阵 §3 口径** |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/audits` | 通用审计查询（`action` 可重复 / `target_type` / `target_id` / `actor_id` / `since` / `until` / `limit` 1–200 / `offset`） | 四个业务角色 `200`（`employee` **仅本人相关**，服务端强制）；`customer_admin` ⇒ `403`「当前岗位不能查看审计日志」；匿名 ⇒ `401` | `employee` ⚠️**仅本人相关** / `department_lead` ✅本租户 / `ceo` ✅ / `super_admin` ✅ / `customer_admin` ❌ —— **已对齐** |
| **GET** | `/api/v1/audits/actions` | **🆕 本轮新增（已实现）**：动作码全集（供界面做动作筛选） | 与「查询」同档：四个业务角色 `200`；`customer_admin` ⇒ `403`；匿名 ⇒ `401` | （同「审计：查询」） |
| — | （审计导出） | **后端零实现**（无任何 audit export 端点） | — | §3「审计：导出」= 仅 `super_admin` ✅ ⇒ **实现缺失（用户裁决：本轮只登记）** |

**响应形状（源码逐字）**
- 记录视图：`{ record_id, action, actor_id, target_type, target_id, phone_masked, detail, occurred_at }`
  （`app/main.py:3783`；`detail` 是**对象**、`occurred_at` 是**带时区时间**）
- 列表信封：`{ items: AuditRecordView[], total, limit, offset }`
- **无详情端点**（记录即全部字段，列表已给全 ⇒ 详情用抽屉就地渲染即可，不需再请求）。

**已实测/已钉住的请求约束（`tests/test_audit_query_api.py`）**
- 未认证 ⇒ `401`；未知动作码 ⇒ `422`「未知的审计动作：xxx」；`limit=0/201`、`offset=-1` ⇒ `422`；
- **时间必须带时区**：`naive`（`2026-09-11T08:00:00`）⇒ `422`；URL 里的 `+00:00` 会被解码成**空格** ⇒ 必须用 `Z` 形态
  （前端一律 `toISOString()`）；
- 跨租户不可见（`X-Tenant-Id` 换成别的 ⇒ `total = 0`）；`tenant_id` 为空的**全局记录不返回**。

## 2. 角色分档与自限口径（**本轮的 P0 修复**）

矩阵 §3「审计：查询」四档 + 末列拒绝 ⇒ 落地方案（与第 7 轮知识域、第 8 轮技能域**同一手法**：实现向矩阵对齐、不改矩阵口径）：

| 角色 | 矩阵口径 | 落地口径（**本轮实现**） |
| --- | --- | --- |
| `employee` | ⚠️ **仅本人相关** | 可查**本租户内 `actor_id == 自己`** 的记录；**服务端强制注入** `actor_id = context.user_id`；**显式传他人 `actor_id` ⇒ `403`**（不静默忽略 —— 静默忽略会让调用方以为"筛过了"，见 §7-#2） |
| `department_lead` | ✅ 本租户 | 本租户全量（可自由使用 `actor_id` 等筛选） |
| `ceo` / `super_admin` | ✅ 本租户 | 同上 |
| `customer_admin` | ❌ | `403`（现状已是 403 ⇒ 不变） |

**为什么必须服务端强制**：`AuditService.query(tenant_id, actor_id=…)` 的 `tenant_id` **必须由鉴权上下文提供**
（`app/audit/service.py` 自述），而 `actor_id` 是**查询参数**（客户端可传）⇒ 若前端"自己限制"，等于**只靠界面隐藏**，
撞宪法「安全校验不得只做在前端」与「数据归属」红线。**该判定放路由层**（需要读查询参数 `actor_id`），
并新增用例逐角色钉死（见 §6）。

## 3. 页面契约（两视图 + 四态）

| 块 | 数据源 | 交互 | 空态口径 |
| --- | --- | --- | --- |
| **审计日志 · 管理视图**（`department_lead` / `ceo` / `super_admin`） | `GET /api/v1/audits`（分页） | 筛选（动作 / 目标类型 / 目标 ID / 操作人 / 时间范围）+ 列表（时间 / 动作 / 操作人 / 目标 / 掩码手机号）+ 行内「详情」抽屉（`detail` 键值对 + `record_id`） | 「本租户还没有审计记录」（解释为什么空） |
| **审计日志 · 我的操作视图**（`employee`） | 同上（**服务端强制自限**） | **不渲染**「操作人」筛选项（自限，避免误以为能查他人）；其余筛选（动作 / 目标 / 时间）可用；列表与详情同上 | 「你还没有审计记录」 |
| **审计导出** | **无接口** | **不做按钮**、不给假入口；页内如实说明「尚未接入」（矩阵要求 `super_admin`，但后端零实现 —— §4 / §7-#4） | 同上 |

**四态**：加载（骨架屏）/ 空（解释为什么空）/ 错误（可重试）/ 无权限（`customer_admin` ⇒ 整页无权限 + 原因，**不请求数据**）。
**导航**：`audit-log` 入口由 `ADMIN_ONLY` 改为 **四个业务角色可见**（矩阵三档都 ✅/⚠️）；`customer_admin` 不显示。
**呈现纪律**（本项目既有口径）：
- `detail` 一律按**键值对**渲染（值做字符串化），**不得**当 HTML 注入；不展示任何堆栈 / SQL / 内部路径；
- `actor_id` / `target_id` 是不透明标识（非手机号）⇒ 原样显示，不解析成姓名；
- 时间显示统一走 `formatDateTime`（本地可复现格式，不用 `toLocaleString`）。

## 4. 本模块**不做**（逐条登记）

| 事项 | 原因 |
| --- | --- |
| **审计导出**（CSV / JSON 下载） | 矩阵给 `super_admin` ✅，但**后端零实现**（无端点、无队列、无过期包）⇒ 界面**不放假按钮**，如实标"尚未接入"，等后端立项（§7-#4） |
| 审计记录的**编辑 / 删除 / 清空** | 审计是**追加型不可变日志**（`app/audit/store.py` 无 UPDATE/DELETE 面）⇒ 不做，也不提供"清空"入口 |
| 跨租户 / 全局（`tenant_id` 为空）记录 | 后端**明确不返回**（`app/main.py:3835` 自述）⇒ 界面不提供该筛选 |
| 实时推送 / 自动刷新 | 后端无 SSE/WS 审计通道 ⇒ 只做"手动刷新"，不假装实时 |
| 审计的**保留策略**界面 | 属商业化契约面（保留策略另有一处接口），不在本模块 |
| 记录级**脱敏开关** | 脱敏在**写入侧**（`redact_payload` / `mask_phone`）⇒ 界面无开关可做 |
