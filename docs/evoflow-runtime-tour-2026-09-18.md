## 5. 最值得吸收的设计（A 级，实机取证）

### 5.1 「问号 + 教程」体系（用户明确要求的能力，此处是全站统一机制）

- **入口**：① **每页右上角「? 使用指南」**（工作流页、任务中心页实测均有）；② **首次进入自动弹一次**（员工页实测自动弹出）；③ 场景化浮窗（「小V可以协助任务 / 问卡点、催办、看谁在忙，交给右侧小V。」，带「打开小V」与「**知道了**」）。
- **骨架**：页签「概览 / 操作 / FAQ / 更多文档」；概览固定四段：**⏱ 30 秒上手 → 1 这是什么 → 2 什么时候用 → 3 最短怎么用**。
- **两个语言手法（比结构更值得抄）**：
  1. **每段结尾给「退出路径」**——员工页「只想聊天问一句 → 用首页 💬 即可。」；任务中心「纯闲聊去首页聊天即可。」（防止用户在不合适的页面里打转）
  2. **直接教「不会点怎么办」**——「不会点：对小V说『记一条待办』或『有哪些待我确认』。」（给不会用界面的人一条自然语言兜底路径）
- **用语**：账本 / 两本账 / 交工 / 确认或打回 / 入职 / 编制 / 在岗 / 自动上班 / 近况。**通篇无技术术语。**

### 5.2 空态与首次使用的处理

- 工作流页空态：图标 + 「还没有工作流」+ **步骤式指引**（「点下方创建 → 在画布选智能体、写步骤 → 点『调试』试跑 → 满意再发布。」）+ **主/次双按钮**（创建空白工作流 / 从模板创建）。
- 任务中心空态：解释 + 「从场景快速创建」4 张场景卡（竞品分析报告 / 代码重构与测试 / 本周工作周报 / 批量数据整理）。
- 工作台输入框下方常驻一行「不会用的兜底」文案。

### 5.3 状态可见性

- 员工页顶部横幅：「1 人**在岗** · 0 项**待批**」——一眼看到资源与待办。
- 工作台 5 个指标卡，其中「异常告警」独立成卡、红色语义。
- 任务中心 7 个状态页签，「异常」独立成一档。

### 5.4 设置面（我们的管理台差距最大的一块）

它的设置是**全屏页 + 左侧分组导航**（基础设置 / 能力与集成 / 数据与资源 / 关于，共 13 个二级项），仅「外观与显示」一页就有：主题三态、**8 色色卡**（含说明「选择色卡后，按钮强调色与背景面板氛围会一起变化」）、自定义背景（图片/视频）、不透明度、液态玻璃（WebGL 预设 + 磨砂强度 / 流体速度 / 背景压暗）、字体大小滑杆。
→ 对比我们：管理台侧栏底部只有「浅色 / 深色 / 跟随系统」三个按钮。

### 6.1 追查：用户报「模型好像只能接入方舟 Agent Plan，不能接 DeepSeek」

**结论：源码层面支持 DeepSeek；但本机界面因上述加载失败而看不到厂商列表。**

**证据（C 级 · 仅来源码快照 `evopanel/src/lib/model-presets.js`，未在本机界面验证）**：
- `PROVIDER_PRESETS` 共 **13 家**：阿里云百炼 / 火山引擎 / 智谱 AI / 胜算云 / 硅基流动 / MiniMax / 月之暗面 Kimi / OpenAI（兼容接口）/ Anthropic / **DeepSeek** / Google Gemini / NVIDIA NIM / Ollama（本地）。
- DeepSeek 条目：`baseUrl: 'https://api.deepseek.com/v1'`，api 类型 `openai-completions`。
- `MODEL_PRESETS.deepseek` 预设：`deepseek-chat`（DeepSeek V3，64k）、`deepseek-reasoner`（DeepSeek R1，64k）。
- 另有兜底口子：`openai` 条目描述原文「也可把接口地址改成 NewAPI / OneAPI / Azure 兼容端 / 自建网关等任意 OpenAI 兼容端点」。

**为什么会产生「只能接方舟」的错觉（两个原因）**：
1. **厂商列表被刻意排序** —— 源码注释原文：`// 支持 Coding Plan 专属接口的三家排在最前：百炼 → 火山 → 智谱`。而 **DeepSeek 在列表第 10 位**，很可能落在可视区之外，需滚动才能看到。
2. **火山引擎条目的描述在推销方舟 Agent Plan** —— 原文：「方舟 Agent Plan：DeepSeek-V4-flash / Kimi-K3 / Doubao-Seed-Evolving / GLM-5.3 等，全模态 + Harness。**套餐请用 /api/plan/v3，勿用按量 /api/v3**」。⇒ 它主推方舟套餐，且**方舟 Agent Plan 本身就含 DeepSeek-V4-flash**。
3. 叠加上述 A 级缺陷（页面加载失败）⇒ 用户看得见的只有报错，更难发现完整列表。

**未验证**：本机 v1.0.3 界面上的厂商列表内容（因页面加载失败，**无法取证**）；`请求参数验证失败`（后端 422）的具体成因未追查（未读 gateway 日志）。

**对研究结论的影响**：本条的「支持 DeepSeek」维持 **C 级**；**不得**据此宣称"已在本机验证可接入 DeepSeek"。
