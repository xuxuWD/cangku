## 2. 信息架构现状（实测还原）

**左栏（`navigation "主导航"`）**——6 组 17 项，**全部默认展开**：

| 组 | 项 |
| --- | --- |
| 对话 | 对话 |
| 任务与项目 | 概览 / 内容工作台 / 历史草稿 / 协同动态 |
| 员工 | 员工与岗位 / 数字员工设置 |
| 知识 | 知识权限管理 |
| 治理 | 安全与审计 / 通知 / 用量与费用 |
| 客户与商务 | 客户 / 商机 / 报价 / 合同 / 进度概览 |
| （底部）外观 | 浅色 / 深色 / 跟随系统 |
| （底部）身份 | `超级管理员` / `admin` |

**主区**：`main` → `h1` 页面标题 + 页面级操作按钮 + 内容区。
**URL 模型**：`?view=<视图键>`（如 `?view=audit`）+ 会话页追加 `?conversation=<会话ID>`。
**路由形态**：全站 `document.querySelectorAll('a[href]').length === 0`（无任何真实链接，导航均为 `div[role=button]`）。

### IA-01 【P1】左栏没有「新建」主按钮

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 全局 / 左栏 |
| 用户角色 | 全部（尤其首次使用者） |
| 问题 | 左栏第一项是分组「对话」下的子项「对话」；**新建入口藏在「对话」页内部**（页面内的「新建会话」按钮）。左栏自始至终没有主操作按钮。 |
| 复现步骤 | ① 打开 `http://127.0.0.1:5180/` → ② 观察左栏 → ③ 对比：「新建会话」按钮位于 `main` 内，不在 `nav` 内 |
| 实际结果 | 左栏仅导航项，无任何主按钮 |
| 预期结果 | 「新建会话 / 新建任务」应常驻左栏首位，一次点击即可开始 |
| 证据 | 无障碍树：`navigation "主导航"` 首项为 `button "对话"`；`main` 内才出现 `button "新建会话"` |
| 影响 | ① 每次开始工作都要"先进页面再找按钮"，多一步；② 新用户看到左栏 17 个名词不知道从哪开始；③ 与主流同类产品（WorkBuddy 左栏首项「＋ 新建任务」、EvoFlow 左栏首项「＋ 新建对话」）方向相反 |
| 整改建议 | 左栏顶部固定「＋ 新建会话」（对话为主线）；任务/内容类另设次入口。**不改页面内部实现**，只加全局入口 |
| 验收标准 | 任意页面下，左栏首项为「＋ 新建会话」，点击后直接进入可输入的新会话；键盘可达；`aria-label` 完整 |
| 工作量 | 小 | 
| 依赖 | 无 |

### IA-02 【P1】会话列表不在左栏，被塞进「对话」页内部

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 全局 / 左栏 vs 对话页 |
| 用户角色 | 全部 |
| 问题 | 会话列表是**对话页内部的一个区域**（`region "会话列表"`，含自己的「全部 / 进行中 / 已归档」页签），与 `region "会话内容"` 并列在 `main` 内。左栏没有任何会话入口。 |
| 复现步骤 | ① 打开 `?view=conversation` → ② 观察 `main` 内并列两个 region；③ 切到 `?view=audit` → 会话列表消失 |
| 实际结果 | 会话列表随「对话」页出现/消失，不是全局常驻 |
| 预期结果 | 会话列表常驻左栏中下部，任意视图下都可见、可直接切换 |
| 证据 | 无障碍树：`main [e30]` 下 `region "会话列表" [e39]` 与 `region "会话内容" [e47]` 为兄弟节点；切到审计页后两会话 region 均不存在 |
| 影响 | **这正是用户投诉的核心**（"对话还是集成到右边页里的，并没有放在左边栏可以新建对话"）。用户在别的页面想回到刚才的会话，必须先切回对话页 |
| 整改建议 | 把会话列表提升到全局左栏（对话页只保留会话内容）；保留「全部/进行中/已归档」筛选 |
| 验收标准 | 在任意视图下左栏都能看到会话列表；点击某会话直接切换；切换后当前视图不变（或按设计明确跳转） |
| 工作量 | 中 |
| 依赖 | 需先定左栏整体结构（与 IA-01 / IA-07 一并设计） |

### IA-03 【P1】点左栏「对话」会丢掉当前打开的会话

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 左栏 → 对话页 |
| 用户角色 | 全部 |
| 问题 | 已打开某会话时（URL 含 `&conversation=conv-...`），点左栏「对话」，**`conversation` 参数被静默丢弃**，回到会话列表；无任何提示。 |
| 复现步骤 | ① 打开 `?view=conversation` → ② 点「新建会话」进入 `?view=conversation&conversation=conv-00c88485e19d` → ③ 点左栏「对话」 → ④ 观察 URL |
| 实际结果 | URL 变为 `?view=conversation`（`conversation` 参数消失） |
| 预期结果 | 点当前模块主入口应保持当前上下文；若确需返回列表，应给出可见反馈 |
| 证据 | 实测前后 URL 对比（`…&conversation=conv-00c88485e19d` → `…?view=conversation`） |
| 影响 | **返回丢状态**（排查文件 A 组明列项）。用户在会话里写了一半，误点左栏即丢失上下文 |
| 整改建议 | 左栏「对话」在已有打开会话时保持不变，或改为"展开会话列表"而非"重置" |
| 验收标准 | 已打开会话时点左栏「对话」，当前会话不丢失；连续点击不产生状态回退 |
| 工作量 | 小 |
| 依赖 | 无 |

### IA-04 【P1】对话页把开发者文案直接暴露给用户

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 对话页 |
| 用户角色 | 全部（含未来客户） |
| 问题 | 页面描述与消息前缀直接出现开发术语与版本状态：<br>· 页面描述「与数字员工对话。会话与消息的**数据模型**、权限与审计都是真实的；助手回复是**后端标注的桩回复**。」<br>· 消息标记「**P1 桩回复**」<br>· 「**默认阶段未接入真实模型**」 |
| 复现步骤 | ① 打开 `?view=conversation` → ② 读页面描述与消息区 |
| 实际结果 | 用户可见技术黑话 + 未完成状态自述 |
| 预期结果 | 面向用户只用业务语言；开发/桩标识只出现在开发环境或调试开关下 |
| 证据 | 页面文本实测：`与数字员工对话。会话与消息的数据模型、权限与审计都是真实的；助手回复是后端标注的桩回复。` / `P1 桩回复` |
| 影响 | ① 「数据模型 / 后端 / 桩回复 / P1」普通用户看不懂（排查文件 D 组"术语是否通俗、无开发黑话"）；② **向客户暴露"这是未接入真实模型的开发版"，有商务风险** |
| 整改建议 | 文案分层：生产环境隐藏技术自述与桩标识；确需告知能力边界时改用业务语言（如"当前为演示回复，尚未接入真实模型，请联系管理员开通"） |
| 验收标准 | 生产构建产物中不出现「桩回复 / P1 / 数据模型 / 后端」等开发术语；能力边界提示为业务语言 |
| 工作量 | 小 |
| 依赖 | 需确认生产环境开关（当前为开发态） |

### IA-05 【P2】全站零个真实链接，导航无法"新开标签 / 复制链接"

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 全局 |
| 问题 | `document.querySelectorAll('a[href]').length === 0`；所有导航项是 `div[role=button]`。 |
| 复现步骤 | ① 打开任意页 → ② 在控制台统计 `a[href]` → ③ 右键任一导航项 |
| 实际结果 | 无链接可右键、无「在新标签页打开」、无「复制链接地址」 |
| 预期结果 | 导航项为真实链接（可中键新开、可复制、可被辅助技术识别为链接） |
| 证据 | DOM 查询返回 0 |
| 影响 | ① 多任务用户无法并排对照两个页面（排查文件高级场景：多窗口/多标签）；② 无法把某个视图发给同事；③ 屏幕阅读器只会读成按钮，弱化"这是跳转"的语义 |
| 整改建议 | 导航项改语义化链接（保留 `?view=` 的 URL 模型即可），保持现有视觉不变 |
| 验收标准 | 左栏每项为 `a[href]`，中键可新开标签；键盘 Tab 可达；Enter 可跳转 |
| 工作量 | 小 |
| 依赖 | 无（URL 模型已具备） |

### IA-06 【P2】非法 `?view=` 静默降级，无提示且不改 URL

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 全局路由 |
| 用户角色 | 全部（尤其收到别人分享链接的人） |
| 问题 | 访问不存在的视图时，**静默渲染「对话」页，URL 仍保留错误参数，没有任何提示或 404 页**。 |
| 复现步骤 | ① 直接打开 `http://127.0.0.1:5180/?view=definitely-not-a-view` → ② 观察渲染结果与 URL |
| 实际结果 | `h1 = 对话`；URL 仍为 `?view=definitely-not-a-view` |
| 预期结果 | 明确提示「该页面不存在或已调整」+ 提供回首页/正确入口 |
| 证据 | 实测：非法 view 的 `h1` 为「对话」，与合法 `?view=audit` 的 `h1`「审计日志」形成对照 |
| 影响 | 用户以为链接有效但内容不对，会怀疑系统出错；排查与支持成本转移给用户 |
| 整改建议 | 未知 view 走显式兜底页（而非默认视图），并给出可点击的正确入口 |
| 验收标准 | 非法 view 渲染兜底提示页；URL 被纠正或提示文案明确说明；不出现无声降级 |
| 工作量 | 小 |
| 依赖 | 无 |

### IA-07 【P2】页面级无面包屑、无返回控件

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 全局 |
| 用户角色 | 全部 |
| 问题 | 全站无面包屑、无"返回上一页"控件。 |
| 复现步骤 | ① 打开 `?view=audit` → ② 查找面包屑/返回按钮 |
| 实际结果 | `[class*=breadcrumb]` 为 `null`；无返回控件 |
| 预期结果 | 深层页面（如 通知 → 运行详情）应有路径指示与返回 |

| 整改建议 | 页面标题区加轻量面包屑（一级足够）；深层详情页加返回 |
| 验收标准 | 二级以上页面显示路径；返回控件可用且语义正确 |
| 工作量 | 小 |
| 依赖 | 需先定页面层级（与 IA-01/IA-02 一并） |

### IA-08 【P2】左栏 6 组全展开且无"全部折叠"，小视口下约一半入口不可见

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 左栏 |
| 用户角色 | 全部 |

| 复现步骤 | ① 打开 5180（视口 980×489）→ ② 查看无障碍树 → ③ 观察哪些项标记 `offscreen` |

### IA-09 【P2】伴侣端登录页无「忘记密码 / 注册 / 帮助」

| 字段 | 内容 |
| --- | --- |
| 模块 / 页面 | 手机伴侣端 · 登录页 |
| 用户角色 | 非技术普通用户 |
| 问题 | 登录页只有 手机号 / 密码 / 动态验证码（如已绑定）/ 登录，**没有任何自助入口**。 |
| 复现步骤 | ① 打开 `http://127.0.0.1:5181/` → ② 清点页面元素 |
| 实际结果 | 表单三项 + 登录按钮；无「忘记密码」「注册申请」「需要帮助」 |
| 预期结果 | 至少提供「忘记密码 / 如何申请账号 / 联系管理员」文字入口 |
| 证据 | 页面文本实测：`工作台伴侣端 / 审批与提醒 / 手机号 / 密码 / 动态验证码（如已绑定）/ 登录` |
| 影响 | **死胡同**：忘记密码或未绑定动态码的用户卡在登录页，无任何下一步指引（系统其实有"注册申请 + 管理员审批"与"管理员重置密码"能力，但用户不知道） |
| 整改建议 | 加三条文字链接：忘记密码 / 申请账号 / 联系管理员；说明审批需要多久 |
| 验收标准 | 登录页有自助入口；点击后给出明确下一步（而非跳到空白页） |
| 工作量 | 小 |
| 依赖 | 需确认对应后端能力与文案口径 |

### IA-11 【P3】概览页空状态文案有一处突兀

| 字段 | 内容 |

## 6. 本批小结

- **P0 = 0**；**P1 = 4**（IA-01 左栏无新建主按钮 / IA-02 会话列表不在左栏 / IA-03 点左栏丢当前会话 / IA-04 开发者文案暴露给用户）；**P2 = 5**；**P3 = 1**。
- **核心结论**：用户投诉的「对话不在左栏」在代码与实测两个层面都已坐实 —— 会话列表是**对话页内部区域**，左栏**没有主操作按钮也没有会话入口**。这不是配色问题，是**信息架构问题**，换皮无法解决。
- 同时**必须纠正两处可能的误判**（避免无端返工）：深链与浏览器后退**都是可用的**（G-01 / G-02），不是"深链打不开"。
- 下一批（批 2 · 核心用户旅程）开始前需要：**一份可用测试账号**（伴侣端登录）与**种子数据**（否则列表类页面只能验空态）。
