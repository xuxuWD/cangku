# 员工手册

> **适用范围**：本手册面向客户方**普通员工 / 部门负责人**（角色 `employee` / `department_lead`），
> 说明「每天怎么用工作台把活派出去、怎么看结果、怎么给结论」。
> **不覆盖**：账号审批、名册与数字员工配置、知识权限、用量与费用、数据导出与租户删除
> —— 那些属管理员职责，见[《客户管理员手册》](customer-admin-handbook.md)。
>
> **口径**：本手册逐条对应**已交付**的功能。凡尚未交付或尚未在真实环境验收的，一律在
> §11「未交付与未验收」里如实列出，**不写进操作步骤**。

## 1. 你有三个入口

| 入口 | 装在哪 | 适合做什么 | 现状 |
|---|---|---|---|
| **网页管理台** | 浏览器打开部署方给你的地址 | 日常主力：对话、任务、通知、查看运行与验收 | 已交付 |
| **手机伴侣端** | 手机浏览器「添加到主屏幕」 | 外出时收提醒、看对话进展、处理待办 | 已交付；**提醒是定时刷新，不是系统推送** |
| **桌面端** | 安装包（Windows） | 把工作台当一个独立应用打开 | 已交付；**安装包尚未签名**，安装时系统可能提示来源不明 |

三个入口用**同一套账号与权限**，看到的业务数据一致。

## 2. 登录

登录标识是**手机号**，在你们公司内部全局唯一。

- 账号不是自助注册就能用的：先**提交注册申请**（手机号、密码、岗位、姓名），
  由**超级管理员审批并指定角色**后才能登录。审批前登录会失败。
- 如果管理员为你开启了**动态验证码**（手机上的验证器 App），登录时除密码外还要填 6 位动态码。
- **密码要求**（注册、本人改密、管理员重置三条路都按同一套规则，且不能由配置关闭）：
  10–128 个字符、不能是纯数字、不能是重复的单一字符、不能是常见弱口令。
- 连续输错会触发**限流**：同一手机号在 5 分钟窗口内失败达阈值后，会提示
  「登录尝试过于频繁，请稍后再试」——稍等几分钟再试即可，这是保护措施，不是账号被封。
- 点「退出」后，**当前这个登录立即失效**（服务端注销），不是等过期才失效。

> 提示：登录失败提示统一为「手机号或密码不正确」，不区分「账号不存在 / 密码错 / 未审批」——
> 这是有意的，避免泄露谁有账号。

## 3. 工作台首页：一句话派活

首页是每天开工的地方：上面是**今天在跑的会话数、数字员工数与未读通知**，下面是最近会话与待办通知。

**最短路径**：① 在中间输入框说清楚你要的结果 → ② 选执行人（数字员工）→ ③ 回车发送。
不知道怎么说时，点一个「试试这样问」的例子，改一改再发。

- 说不清「要什么」时，可以先问它「你打算怎么做」，确认思路再让它动手。
- 输入框里可用指令：`/new`（新开一件事）、`/stop`（停下）、`/help`（看可用指令）、`/status`（看状态）。
- 快捷键：`?` 打开本页使用指南、`Esc` 关浮层、`Enter` 发送（`Shift + Enter` 换行）。

## 4. 对话：一件事的完整记录

一个对话 = 一件事的完整记录：消息、审批、产出都留在里面，随时能翻回去看。

- **左边**是和数字员工的消息；**右边**是这次执行的过程、审批与产物。
- **上方的模式**决定这件事按什么口径执行（例如是否需要逐步确认）。
- 需要你拍板时，会话里会出现**审批卡**：点「同意并继续」它才继续做。

**最短路径**：① 说清楚要什么 → ② 弹审批卡时点「同意并继续」→ ③ 右侧看过程，等它交工。

### 4.1 把对话分享给同事

对话可以分享给同事协作，**按人给权限**：只读（能看）或可写（能发言、能推进）。
分享后，这件事的活动会出现在「协同动态」里，谁在什么时候推动了哪一步都能查到。

### 4.2 导出或删除自己的对话

你可以**导出**自己的对话留档，也可以**物理删除**自己的对话。
删除是不可撤销的：删掉之后对话内容不再存在，请先导出再删。

## 5. 任务页：做内容（图文草稿）

「任务」页有两个页签，都属同一件事的前后半段：

| 页签 | 干什么 |
|---|---|
| **任务** | 填主题与素材 → 生成草稿 → 在右侧改 → 「保存修改」→「确认并下载」 |
| **历史草稿** | 回看以前生成的草稿，按状态筛选，接着改 |

**最短路径**：① 填主题与至少一条正文摘录 → ② 开始生成 → ③ 右侧改好「保存修改」→「确认并下载」（Markdown）。

> 边界（如实）：本页产出**草稿**；**自动发布到公众号尚未验收**，现在由人工下载后自行发布。

## 6. 运行详情：看过程、叫停、给结论

从对话或通知点进某次执行，就是「运行详情」页。

- **上面四个数字 + 「运行信息」**：进度与耗时、执行状态。
- **「交付」**：这次交了什么（产物清单、结构判定）、**验收结论**。
- **「事件时间线」**：全过程记录（只渲染允许展示的字段）。
- **能发起的动作**：
  1. **叫停**：「暂停运行」/「恢复」/「取消」。**取消不可撤销**，会先让你确认。
  2. **验收**：运行结束后，在「交付」里点**「确认完成」**或**「打回重做」**。
     - **打回必须写原因**（≤500 字），原因会留在记录里，便于重做时对照。
     - 打回**只记录结论与原因**，不会改动原运行的状态和产物；要重做请回到发起这次运行的对话页
       （那里还持有原调用，可用「一键重做」）。
     - 只有**任务发起人、CEO 或超级管理员**能验收。
  3. **沉淀**：**只有「确认完成」之后**才出现**「存成任务」**——把这次的做法存成一个可再跑的任务，
     执行员工、风险档与预算由服务端按这次运行自动带过来；**一次运行只能沉淀一次**，重复点击不会多建任务。

## 7. 通知：结果回来了、有事等你

左栏「更多」里的「通知」是你的收件箱，**未读条数**会显示在入口上。

你会在这里收到：**运行失败 / 被取消**、**审批被驳回**、**内容发布转人工接管**、**账号注册通过**等。

- 点「打开…」**直达**对应页面（会顺手标为已读）。
- 「全部 / 未读」筛选；「全部标记已读」只影响你自己，不会改动别人的。
- 某一条点不开时，行内会写明原因（例如该类型的处理页尚未交付）。

## 8. 你能看到哪些审批

**审批集中在 CEO 与超级管理员**——这是有意的（发起人不得审批自己发起的事）。
所以在待办列表里：

| 待办类型 | 谁能看到 |
|---|---|
| 任务审批、计划提案、运行审批 | 仅 CEO / 超级管理员 |
| 账号注册 | 仅超级管理员 |

**你能做的「结论」是验收**（见 §6）——如果这次执行是你发起的。

## 9. 页面里都有「使用指南」

每一页右上角都有 **「? 使用指南」**（快捷键 `?`），四段讲清：30 秒上手 / 这是什么 / 什么时候用 / 最短怎么用，
每段结尾给退出路径。忘了怎么点，先按 `?`。

## 10. 常见问题

| 现象 | 先这样看 |
|---|---|
| 登录提示手机号或密码不正确 | 确认手机号与密码；若管理员开了动态验证码，确认动态码是否已过期（动态码 30 秒一换） |
| 提示登录尝试过于频繁 | 等几分钟再试；这是限流保护 |
| 左侧找不到某个入口 | 多半是角色权限：审批类只对 CEO / 超管开放，管理员功能只对管理员开放 |
| 审批卡不出现 | 运行还没走到需要拍板的那一步；可以先问它「你打算怎么做」 |
| 数字员工半天没动静 | 打开该对话看右侧过程与事件时间线，确认它卡在哪一步；必要时「暂停 / 取消」 |
| 「确认完成 / 打回重做」不出现 | 运行还没结束，或你不是发起人 / CEO / 超管 |
| 「存成任务」不出现 | 要先「确认完成」；已沉淀过就不会再出现 |
| 通知一直没来 | 伴侣端的提醒是**定时刷新**而非系统推送；打开页面下拉刷新即可 |

## 11. 未交付与未验收（如实说明）

以下能力**当前不可用或不完整**，请勿按「应该能用」预期：

1. **自动化调度**：把任务「设为自动化」（定时跑）**尚未交付**；现在只能手动触发。
2. **任务中心的列表 / 详情页**：沉淀出来的任务有编号、可在审计与运行详情里追溯，
   但**还没有任务列表与详情页面**。
3. **公众号自动发布**：真实发布未验收，请下载草稿后人工发布。
4. **手机端系统推送**：伴侣端提醒是轮询，不是推送。
5. **桌面端安装包**：未做代码签名，安装时系统可能提示来源不明；
   「旧版 → 新版」自动更新链路**未在干净机器上验收**。
6. **真实模型 / 网页抓取**：是否启用取决于你们部署时的配置；**未用真实账号做过验收**。

## 12. 需要帮忙时

先按 §10 自助排查；仍解决不了，请带上这些信息联系你们的管理员或平台方（见[《故障手册》](troubleshooting-handbook.md) §3）：

- 报错**原文**（截图或复制文字，不要转述）
- 发生**时间**（大概到分钟）
- **影响谁**（只有你，还是同岗位都这样）
- 出问题**前动过什么**（刚改了配置 / 刚分享过对话 / 刚重启过电脑）
