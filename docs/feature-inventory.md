## 1. 六要素定义（宪法 2.1 原文口径）

| 要素 | 含义 | 不合格表现 |
| --- | --- | --- |
| **谁用** | 使用者与角色 | 写「用户」而不说是哪类角色 |
| **输什么** | 输入（页面 / 接口 / 上传文件 / 配置） | 只说「有输入」不说字段与约束 |
| **得什么结果** | 可验收的输出与**落点**（数据、审计、通知） | 只说"成功"不说落在哪里 |
| **角色与权限** | 是否需登录 / 允许哪些角色 / 是否只能操作自己的数据 / 无权限返回什么 | 只在前端藏按钮 |
| **正常流程** | 主流程步骤（走通即成功） | 只给一句话概述 |
| **异常与边界** | 非法输入、越权、并发、超时、失败与恢复 | 只写"异常时提示错误" |
