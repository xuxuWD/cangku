# TabTin 硬线规则拆解（2026-09-23）

本目录是一次对 **TabTin** 的**代码级拆解记录**（2026-09-22~23），以及同一时间跨度内
**用户与 AI 的全部需求沟通原始记录**的归档。

## 为什么放在这里

此前关于 TabTin 的研读成果只有一份
[`docs/tabtin-source-study-and-adaptation-plan.md`](../tabtin-source-study-and-adaptation-plan.md)
（**接口面/能力面**层面的研读）。本次拆解深入到**代码级**——具体到「同一份安全规则在仓库里
有几份拷贝、各自怎么漂移、怎么收敛」，以及**一批只有实跑才能发现的结论**（见 `02` §3）。
另把散落在会话里的需求沟通**落进仓库**，避免只存在于对话记录中。

## 边界（先读这一段）

- TabTin 在本项目的定性是**只读研读（第三种模式）**：
  **不搬代码、不接适配器、连接都不接**（判据见 [`docs/architecture.md`](../../architecture.md) §外部集成的判据）。
- 因此本目录**只放提炼与记录，不含任何 TabTin 源码**。
- 同理，**EvoFlow 的源码研究副本**（`_evoflow-study/`）也在同一口径下 ——
  其许可为 PolyForm Non-Commercial，**不进本仓库**；其研读成果见
  [`docs/evoflow-*.md`](../) 四份既有文档。
- 本目录内容**不改动本项目任何口径**；与本项目真源冲突时以真源为准。
