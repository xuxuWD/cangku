# 协同动态表现层

## 定位

“协同动态”是公司工作台的数据总览/行动中心中的可选表现层，用于把真实任务状态和数字员工协作过程展示得更直观。它不是任务执行引擎，不拥有独立业务状态，也不能代替任务详情、审批记录或审计日志。

## 数据来源

- 所有状态来自工作台统一任务事件和任务查询接口。
- 每条动态必须带租户、项目、任务号、数字员工、责任人、状态和发生时间。
- 前端只读取当前用户有权限访问的任务，不接受来自浏览器的直接写入动作。
- 动画结束不代表任务完成；只有服务端状态变更后才更新为完成。

## 第一版范围

先实现静态状态列表和轻量状态卡片，覆盖：

- 执行中
- 等待审批
- 等待发布
- 已完成
- 需要人工处理

点击动态后进入标准任务详情，查看步骤、产物、审批、失败原因和证据引用。支持关闭动态和低性能设备降级。

## 后续动画层

任务、权限、事件和审计稳定后，可增加 PixiJS/Spine 或其他动画层。动画层必须：

1. 只订阅受保护的实时事件或短轮询结果。
2. 不复用第三方项目的人物、办公室背景或未确认版权素材。
3. 提供减少动态效果选项，并在异常、断线和无权限时显示静态状态。
4. 不开放无认证 Action Gateway，不允许前端直接触发任务、发布或权限变更。

## 验收条件

- 跨租户任务不会出现在动态列表中。
- 刷新、重连和重复事件不会产生重复动态。
- 动态状态与任务详情、审批状态保持一致。
- 后端任务失败时，界面不会显示“已完成”。
- 普通员工只能看到授权范围内的动态，CEO/超级管理员可按权限查看汇总。
- 关闭动画后，核心任务信息和操作入口仍完整可用。
